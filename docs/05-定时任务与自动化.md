# 05 定时任务与自动化

> 让 AI 系统自动运行，无需人工干预

## 1. Hermes Cron 系统

Hermes 内置定时任务调度器，支持 cron 表达式和自然语言：

```bash
# 查看已有任务
/cron list

# 创建任务（每天14:00执行）
/cron add --name "知识库更新" --schedule "every day 14:00" --prompt "更新AI技术知识库，采集今天的AI新闻并整理入库"

# 每小时执行
/cron add --name "区块链采集" --schedule "every 1h" --prompt "采集最新区块链新闻"

# 暂停/恢复
/cron pause <job_id>
/cron resume <job_id>
```

## 2. 我的 Cron 任务配置

```yaml
# 4 个定时任务示例

# 1. 知识库更新 - 每天 14:00
schedule: "every day 14:00"
prompt: "更新AI技术知识库"
skills: [llm-wiki]
deliver: local

# 2. 区块链文章 - 每小时:05
schedule: "5 * * * *"
prompt: "采集区块链新闻，生成文章，推送到微信"
deliver: weixin

# 3. AI科技采集 - 每6小时
schedule: "every 6h"
prompt: "采集AI科技新闻"
skills: [llm-wiki]
deliver: local

# 4. 知识库清理 - 每天 23:30
schedule: "every day 23:30"
script: "scripts/cleanup.py"
no_agent: true
```

## 3. 任务投递目标

```yaml
deliver:
  - local        # 只保存，不推送
  - weixin       # 推送到微信
  - origin       # 回复到发起会话
```

## 4. 技能绑定

给 Cron 任务绑定特定技能，确保执行时加载正确的知识：

```bash
/cron add --name "wiki更新" --schedule "every day 14:00" \
  --skills llm-wiki --prompt "更新知识库"
```

## 5. 纯脚本任务（不调用 LLM）

不需要 AI 推理的任务，用 `no_agent` 模式省 token：

```python
# scripts/cleanup.py
import os, shutil

# 清理 30 天前的临时文件
cache_dir = os.path.expanduser("~/.hermes/cache")
# ... 清理逻辑

print("清理完成")
```

## 6. 任务链

任务之间可以传递上下文：

```yaml
# 任务A：采集数据
job_a:
  prompt: "采集今日AI新闻"

# 任务B：处理任务A的输出
job_b:
  prompt: "将以下新闻整理为知识库格式"
  context_from: [job_a]
```

## 常见问题

**Q: Cron 任务没有执行？**
A: 检查 `hermes cron list` 确认任务状态，gateway 必须在运行。

**Q: 任务执行超时？**
A: Cron 任务有 3 分钟硬限制，复杂任务拆分成多个小任务。

**Q: 怎么看任务执行结果？**
A: `hermes cron logs` 或查看 `~/.hermes/logs/agent.log`。
