# 01 环境搭建

> 从零配置 Windows 10 上的 AI 开发环境

## 1. 安装 Python

```bash
# 推荐 3.11.x，从 python.org 下载
# 安装时勾选 "Add to PATH"

# 验证
python --version
pip --version
```

## 2. 安装 Ollama

```bash
# 从 https://ollama.com 下载 Windows 安装包
# 安装后自动作为服务运行

# 验证
ollama --version
```

## 3. 安装 Hermes Agent

```bash
# 方式一：pip 安装
pip install hermes-agent

# 方式二：从源码
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
pip install -e .

# 验证
hermes --version
```

## 4. 安装 uv（可选，更快的包管理）

```bash
pip install uv
```

## 5. 配置目录

Hermes 的所有配置、日志、会话都存在 `~/.hermes/` 下：

```
~/.hermes/
├── config.yaml      # 主配置
├── .env             # API 密钥（仅密钥）
├── logs/            # 日志
├── sessions/        # 会话历史
├── skills/          # 技能
└── plugins/         # 插件
```

## 6. 验证环境

```bash
python --version          # 3.11.x
ollama --version          # 最新版
ollama list               # 空列表正常，下一步下模型
hermes --version          # 最新版
nvidia-smi                # 确认 GPU 可用
```

## 常见问题

**Q: Python 找不到？**
A: 检查 PATH 环境变量，或用 `py --version` 试试。

**Q: Ollama 安装后没反应？**
A: Ollama 作为 Windows 服务运行，打开 `http://localhost:11434` 验证。

**Q: nvidia-smi 报错？**
A: 更新 NVIDIA 驱动到最新版。去 https://www.nvidia.com/drivers 下载。
