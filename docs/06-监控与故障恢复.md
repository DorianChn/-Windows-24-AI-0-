# 06 监控与故障恢复

> 让 AI 系统 7×24 稳定运行，崩溃自动恢复

## 1. 日志体系

Hermes 自带日志，存放在 `~/.hermes/logs/`：

| 文件 | 内容 | 级别 |
|------|------|------|
| agent.log | Agent 完整日志 | INFO+ |
| errors.log | 错误和警告 | WARNING+ |
| gateway.log | Gateway 日志 | INFO+ |

```bash
# 实时查看日志
hermes logs --follow

# 查看错误
hermes logs --level warning

# 查看特定会话
hermes logs --session <session_id>
```

## 2. Gateway 看门狗

桌面应用内置 watchdog，Gateway 崩溃后自动重启。

原理：
```
桌面 App → 启动 Gateway → 定时检查进程 → 崩溃时自动拉起
```

## 3. VBS 开机自启（幂等）

防止 Gateway 双实例的开机自启方案：

```vbs
' Hermes_Gateway_Idempotent.vbs
' 检测已有 Gateway 进程则跳过，防双实例

Set objWMI = GetObject("winmgmts:\\.\root\cimv2")
Set colProcesses = objWMI.ExecQuery("SELECT * FROM Win32_Process WHERE Name='python.exe'")

For Each objProcess in colProcesses
    If InStr(objProcess.CommandLine, "gateway run") > 0 Then
        WScript.Quit  ' 已有实例，退出
    End If
Next

' 没有实例，启动 Gateway
Set objShell = CreateObject("WScript.Shell")
objShell.Run "python -m hermes gateway run", 0, False
```

放在启动文件夹：
```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\
```

## 4. 健康检查脚本

```python
# scripts/health-check.py
import subprocess
import psutil

def check_gateway():
    for proc in psutil.process_iter(['name', 'cmdline']):
        try:
            if proc.info['name'] == 'python.exe':
                cmdline = ' '.join(proc.info['cmdline'] or [])
                if 'gateway run' in cmdline:
                    return True
        except (psutil.NoSuchProcess, psutil.AccessDenied):
            pass
    return False

def check_ollama():
    try:
        result = subprocess.run(['ollama', 'list'], capture_output=True, timeout=5)
        return result.returncode == 0
    except:
        return False

def check_gpu():
    try:
        result = subprocess.run(['nvidia-smi'], capture_output=True, timeout=5)
        return result.returncode == 0
    except:
        return False

if __name__ == '__main__':
    status = {
        'gateway': check_gateway(),
        'ollama': check_ollama(),
        'gpu': check_gpu(),
    }
    for service, ok in status.items():
        print(f"{'✅' if ok else '❌'} {service}")
```

## 5. 常见故障排查

### Gateway 不回复消息

```bash
# 1. 检查进程是否在
powershell "Get-CimInstance Win32_Process | Where {$_.CommandLine -match 'gateway run'}"

# 2. 看日志
hermes logs --level error --tail 50

# 3. 检查 iLink 连接
hermes gateway status
```

### Ollama 不响应

```bash
# 1. 检查服务
curl http://localhost:11434

# 2. 重启
ollama serve

# 3. 检查显存
nvidia-smi
```

### 显存被占满

```bash
# 查看谁在用显存
nvidia-smi

# Ollama 会自动管理，但如果有僵尸进程：
taskkill /PID <pid> /F
```

## 6. 关键教训

**永远不要同时跑两个 Gateway。** iLink 单账号只允许一个长连接，双实例会导致消息丢失和反复崩溃。用 VBS 脚本的幂等检测来防止。
