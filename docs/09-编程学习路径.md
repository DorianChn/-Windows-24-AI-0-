# 09 编程学习路径

> 闽江大学 × 塞浦路斯欧洲大学 计算机科学与技术专业学习指南

## 大一：打基础

### 第一学期

#### 数学基础
- **高等数学** - 微积分、极限、导数
- **线性代数** - 矩阵、向量空间、线性方程组
- **学习资源** - B站宋浩老师、同济版教材

#### 编程入门
- **C语言** - 语法基础、指针、结构体
- **学习资源** - 《C Primer Plus》、郝斌C语言

#### 英语能力
- **大学英语** - 四级水平
- **学习资源** - 墨墨背单词、可可英语

### 第二学期

#### 数学进阶
- **概率论与数理统计** - 概率、统计、随机变量
- **学习资源** - B站宋浩老师

#### 数据结构
- **核心内容** - 数组、链表、树、图、排序、查找
- **学习资源** - 《数据结构》严蔚敏、LeetCode

#### 面向对象
- **C++或Java** - 类、继承、多态
- **学习资源** - 《C++ Primer》、B站黑马程序员

## 大二：专业核心

### 第一学期

#### 计算机组成原理
- **核心内容** - CPU、内存、指令系统
- **学习资源** - 《计算机组成原理》唐朔飞

#### 操作系统
- **核心内容** - 进程、内存、文件系统
- **学习资源** - 《操作系统概念》、MIT 6.S081

#### 数据库原理
- **核心内容** - SQL、关系模型、设计
- **学习资源** - 《数据库系统概论》王珊

### 第二学期

#### 计算机网络
- **核心内容** - TCP/IP、HTTP、网络安全
- **学习资源** - 《计算机网络》谢希仁

#### 软件工程
- **核心内容** - 开发流程、项目管理
- **学习资源** - 《软件工程》张海藩

#### 算法设计
- **核心内容** - 排序、搜索、动态规划
- **学习资源** - 《算法导论》、LeetCode

## 大三：方向选择

### AI/机器学习方向

#### 人工智能
- **核心内容** - 搜索、机器学习、神经网络
- **学习资源** - 《人工智能：一种现代方法》、吴恩达课程

#### 机器学习
- **核心内容** - 监督学习、无监督学习
- **学习资源** - 《机器学习》周志华、sklearn文档

#### 深度学习
- **核心内容** - 神经网络、CNN、RNN
- **学习资源** - PyTorch文档、fast.ai课程

### 系统开发方向

#### Web开发
- **前端** - HTML/CSS/JavaScript、Vue/React
- **后端** - Python Flask/FastAPI、Java Spring
- **学习资源** - MDN文档、Flask官方教程

#### 移动开发
- **Android** - Java/Kotlin、Android Studio
- **iOS** - Swift、Xcode
- **学习资源** - 官方文档、B站教程

### 数据科学方向

#### 数据分析
- **核心内容** - pandas、numpy、matplotlib
- **学习资源** - 《利用Python进行数据分析》

#### 大数据技术
- **核心内容** - Hadoop、Spark
- **学习资源** - 官方文档、尚硅谷教程

## 大四：实践输出

### 毕业设计
- **选题方向** - 结合兴趣和就业方向
- **技术栈** - 选择熟悉的技术
- **时间规划** - 前期调研、中期开发、后期完善

### 实习准备
- **简历制作** - 突出项目经验
- **面试准备** - 算法题、技术问答
- **求职渠道** - 牛客网、BOSS直聘、实习僧

## 学习建议

1. **每天坚持** - 编程是技能，需要练习
2. **项目驱动** - 做项目比看书更有效
3. **善用搜索** - 遇到问题先搜索
4. **参与开源** - 提升实战能力
5. **保持好奇** - 技术更新快，持续学习
