## 服务器部署步骤

### 1. 购买服务器

**阿里云推荐**：

1. 访问 [阿里云ECS](https://www.aliyun.com/product/ecs)
2. 选择配置：
   - 地域：华东1（杭州）或华东2（上海）
   - 实例规格：ecs.t6-c1m2.large（2核2G）或 ecs.c6.large（2核4G）
   - 系统盘：40-80GB SSD
   - 操作系统：Ubuntu 22.04 LTS
   - 带宽：1-5Mbps
3. 购买并获取公网IP

### 2. 连接服务器

```bash
# 使用SSH连接
ssh root@你的服务器IP

# 或使用密钥
ssh -i your-key.pem root@你的服务器IP
```

### 3. 一键部署脚本

```bash
#!/bin/bash
# server-setup.sh - 服务器一键部署

set -e

echo "🚀 开始部署Hermes到服务器..."

# 更新系统
apt update && apt upgrade -y

# 安装依赖
apt install -y python3 python3-pip python3-venv git curl wget

# 创建用户
useradd -m -s /bin/bash hermes
echo "hermes:your-password" | chpasswd

# 切换到hermes用户
su - hermes << 'EOF'

# 安装Hermes
pip3 install hermes-agent

# 创建配置目录
mkdir -p ~/.hermes

# 配置环境变量
cat > ~/.hermes/.env << 'ENVEOF'
# 阿里云百炼
DASHSCOPE_API_KEY=sk-your-api-key

# 其他配置
ENVEOF

# 配置Hermes
cat > ~/.hermes/config.yaml << 'CONFIGEOF'
model:
  default: deepseek-v4-flash
  provider: alibaba
  context_length: 65536

providers:
  alibaba:
    base_url: https://ws-d2zlnzz8btbed5od.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
    request_timeout_seconds: 120
    stale_timeout_seconds: 90

compression:
  summary_model: deepseek-v4-flash

terminal:
  backend: local
CONFIGEOF

echo "✅ Hermes配置完成"

EOF

# 配置systemd服务
cat > /etc/systemd/system/hermes.service << 'SERVICEEOF'
[Unit]
Description=Hermes AI Agent
After=network.target

[Service]
Type=simple
User=hermes
WorkingDirectory=/home/hermes
ExecStart=/home/hermes/.local/bin/hermes gateway run
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
SERVICEEOF

# 启用服务
systemctl daemon-reload
systemctl enable hermes
systemctl start hermes

echo "✅ Hermes服务已启动"
echo "📋 查看状态: systemctl status hermes"
echo "📋 查看日志: journalctl -u hermes -f"
```

### 4. 运行部署脚本

```bash
# 上传脚本到服务器
scp server-setup.sh root@你的服务器IP:/tmp/

# 连接服务器
ssh root@你的服务器IP

# 运行脚本
chmod +x /tmp/server-setup.sh
/tmp/server-setup.sh
```

### 5. 验证部署

```bash
# 检查服务状态
systemctl status hermes

# 查看日志
journalctl -u hermes -f

# 测试连接
curl http://localhost:8080/health
```

## 常见问题

### Q: 服务器部署后微信Bot不回复？

### Q: 如何更新Hermes？
A: `pip3 install --upgrade hermes-agent && systemctl restart hermes`

### Q: 服务器费用太高？
A: 选择入门级配置，或使用本地部署

### Q: 数据安全吗？
A: 云端服务器数据加密存储，定期备份
