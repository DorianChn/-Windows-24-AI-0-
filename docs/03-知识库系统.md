# 03 知识库系统

> 用 Obsidian + LLM Wiki 构建结构化知识管理

## 1. 安装 Obsidian

从 https://obsidian.md 下载安装。

## 2. 创建 Vault

按领域拆分独立 Vault，每个 Vault 独立管理：

```
D:\知识库\
├── AI技术/           # AI/ML 技术知识
│   ├── .obsidian/
│   ├── index.md
│   └── 知识库看板.md
├── 加密货币/         # 区块链/加密货币
│   ├── .obsidian/
│   ├── index.md
│   └── 知识库看板.md
└── 计算机科学/       # CS 基础
    ├── .obsidian/
    ├── index.md
    └── 知识库看板.md
```

每个 Vault 内部按类型分目录：

```
AI技术/
├── 概念_(concepts)/     # 概念解释
├── 实体_(entities)/     # 工具/框架/人物
├── 原始资料_(raw)/      # 原始笔记
└── 操作指南_(howto)/    # 操作步骤
```

## 3. 安装 LLM Wiki Skill

LLM Wiki 是 Hermes 的知识库管理技能，自动将内容整理为 interlinked markdown：

```bash
# 在 Hermes 中加载
hermes skills install llm-wiki
```

## 4. 配置自动更新 Cron

每天定时让 AI 采集、整理、写入知识库：

```bash
# 在 Hermes 中创建定时任务
/cron add --name "知识库更新" --schedule "every day 14:00" --prompt "更新AI技术知识库"
```

## 5. Dataview 插件

安装 Obsidian 的 Dataview 插件，用 SQL 查询知识库：

```dataview
TABLE file.ctime AS 创建时间, file.size AS 大小
FROM "概念_(concepts)"
SORT file.ctime DESC
LIMIT 10
```

## 6. 知识库看板

在每个 Vault 根目录创建看板：

```markdown
# 知识库看板

## 最近更新
```dataview
TABLE file.mtime AS 更新时间
FROM ""
SORT file.mtime DESC
LIMIT 10
```

## 统计
```dataview
LIST
FROM ""
GROUP BY file.folder
```
```

## 常见问题

**Q: 知识库会无限增长吗？**
A: 不会。Hermes 有 Curator 机制，自动归档长期不用的内容。

**Q: 多个 Vault 怎么统一搜索？**
A: Obsidian 的全局搜索跨 Vault，或用 Hermes 的 session_search。

**Q: 目录命名为什么要用下划线+括号？**
A: `中文_(英文)` 格式兼顾中文可读性和英文兼容性，避免路径编码问题。
