# 07 云端模型接入

> 本地模型做主力，云端模型做辅助——混合架构才是最优解

## 为什么需要云端模型

本地模型（Ollama）的优点是零费用、隐私好，但有两个场景不够用：

1. **上下文压缩** — 压缩长对话需要快速处理大量token，本地模型太慢
2. **复杂任务** — 代码生成、深度分析等场景，云端大模型效果明显更好

最佳实践：日常对话用本地模型（免费），压缩和复杂任务用云端模型（按量付费）。

## 推荐云端模型

| 模型 | 提供商 | 价格 | 适合场景 |
|------|--------|------|---------|
| deepseek-v4-flash | 阿里云百炼 | ¥0.2/百万token | 压缩、日常辅助 |
| qwen3.5-flash | 阿里云百炼 | ¥0.1/百万token | 最便宜的选项 |
| deepseek-chat | DeepSeek官方 | ¥1/百万token | 复杂推理 |

## 接入阿里云百炼

### 1. 注册并获取API Key

1. 访问 https://bailian.console.aliyun.com/
2. 开通百炼服务
3. 创建API Key
4. 记录专属端点URL

### 2. 配置 .env

在 `~/.hermes/.env` 中添加：

```bash
DASHSCOPE_API_KEY=your_api_key_here
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

### 3. 配置 config.yaml

```yaml
# 主模型用本地
model:
  provider: ollama
  model: qwen3:64k
  base_url: http://localhost:11434/v1

# 压缩用云端
compression:
  provider: alibaba
  model: deepseek-v4-flash
```

## 模型快捷切换

在Hermes中设置别名，随时切换：

```
/model local    → qwen3:64k（本地，免费）
/model deep     → deepseek-v4-flash（云端，快速）
```

## 费用控制

云端模型按token计费，几个省钱技巧：

1. **关闭思考模式** — qwen3默认输出思考过程，多消耗token：
   ```yaml
   model:
     extra_body:
       enable_thinking: false
   ```

2. **精简工具集** — 微信端只开必要的工具，减少每次请求的schema token：
   ```yaml
   platform_toolsets:
     weixin:
       enabled: [terminal, web, file, memory, todo]
   ```

3. **压缩用便宜模型** — 压缩不需要最强模型，deepseek-v4-flash足够

4. **本地优先** — 能用本地解决的不用云端

## 混合架构示意

```
用户消息
  │
  ├── 日常对话 → 本地 qwen3:64k（免费，20-30 token/s）
  │
  ├── 上下文压缩 → 云端 deepseek-v4-flash（¥0.2/百万token）
  │
  └── 复杂任务 → 云端 deepseek-v4-flash（更强的推理能力）
```

## 常见问题

**Q: 云端模型会不会很贵？**
A: 日常用压缩+辅助，一天大概几毛钱。如果全用本地，就是0元。

**Q: 没有VPN能用阿里云百炼吗？**
A: 可以，阿里云是国内服务，直连就行。

**Q: API Key泄露了怎么办？**
A: 立即去百炼控制台删除旧Key，创建新Key。Key只存在.env文件中，不要提交到Git。

**Q: 可以同时用多个云端提供商吗？**
A: 可以。config.yaml中配置主模型和压缩模型用不同provider即可。
