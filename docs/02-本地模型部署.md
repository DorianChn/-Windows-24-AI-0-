# 02 本地模型部署

> 用 Ollama 在本地跑大模型，零 API 费用

## 1. 下载模型

```bash
# 主力模型：通义千问，中文效果好，支持 64K 上下文
ollama pull qwen3:64k

# 备用轻量模型
ollama pull llama3.2:3b

# 代码模型（可选）
ollama pull qwen2.5-coder:7b

# 视觉模型（可选，用于图片理解）
ollama pull minicpm-v
```

## 2. 显存管理

8GB 显存的核心原则：**一次只跑一个模型**。

| 模型 | 显存占用 | 用途 |
|------|---------|------|
| qwen3:64k | ~5.2GB | 日常对话、知识库问答 |
| llama3.2:3b | ~2.0GB | 轻量快速任务 |
| qwen2.5-coder:7b | ~4.7GB | 代码生成 |
| minicpm-v | ~5.5GB | 图片理解 |

```bash
# 查看当前显存使用
nvidia-smi

# Ollama 会自动管理模型加载/卸载
# 超过显存时会卸载旧模型加载新模型
```

## 3. 配置 Hermes 使用本地模型

在 `~/.hermes/config.yaml` 中：

```yaml
model:
  provider: ollama
  model: qwen3:64k
  base_url: http://localhost:11434/v1
```

## 4. 性能优化

### 关闭思考模式

qwen3 默认开启 thinking 模式（输出思考过程），会多消耗 token：

```yaml
# config.yaml
model:
  extra_body:
    enable_thinking: false
```

### 上下文长度

qwen3:64k 支持 65536 token 上下文，足够大多数场景。

```bash
# 测试推理速度
ollama run qwen3:64k "你好，请用中文介绍一下自己"
```

## 5. 模型别名（方便切换）

在 Hermes 中设置快捷切换：

```
/model local    → qwen3:64k（本地）
/model deep     → deepseek-v4-flash（云端备用）
```

## 常见问题

**Q: 模型下载太慢？**
A: Ollama 默认从官方下载，有 VPN 更快。也可以用国内镜像源。

**Q: 显存不够？**
A: 换小模型（llama3.2:3b 只需 2GB），或用量化版本。

**Q: 推理速度慢？**
A: RTX 5060 跑 qwen3:64k 大约 20-30 token/s，日常够用。
